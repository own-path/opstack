# opstack — my default engineering workflow

Use the installed opstack-mode skill by default for my non-trivial coding tasks without waiting for me to invoke it. Read only the workflow skills relevant to the task. Keep trivial edits direct and proportionate. For discovery and review requests, preserve their read-only scope.

Understand the repository and applicable instructions before edits. Own architecture, integration, and verification. Verify delegated work yourself where delegation is explicitly authorized and available; otherwise work sequentially. Before commits, review affected state machines at the scale of the change, including retries, concurrency, restarts, and ownership. Prove confirmed bugs with meaningful regression evidence, and keep the project's state-machine document current when appropriate.

For UI work, check real interaction states, mobile behavior, accessibility, and purposeful motion. Run the relevant checks against the actual changed build. Report the outcome, checks actually run, and remaining limits plainly. Preserve unrelated work and existing personal instructions. Apply project and organization rules when they conflict with personal preferences. Workflow activation never expands authorization to publish, merge, message others, or change accounts.
