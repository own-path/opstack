# Canvas Design

Use this skill to create static visual work as designed artifacts, not generic layouts. Output only `.md`, `.pdf`, and `.png` files unless the user explicitly asks for another format.

Complete the work in two steps:

1. Create a design philosophy as a `.md` file.
2. Express that philosophy on a canvas as a `.pdf` or `.png` file.

## Design Philosophy Creation

Create a visual philosophy, not a layout template. The philosophy should be interpreted through form, space, color, composition, imagery, graphics, shapes, patterns, and minimal text used as a visual accent.

Name the movement in one or two words, such as "Brutalist Joy", "Chromatic Silence", or "Metabolist Dreams".

Articulate the philosophy in four to six concise paragraphs covering:

- space and form
- color and material
- scale and rhythm
- composition and balance
- visual hierarchy

Avoid redundancy: mention each design aspect once. Stress craftsmanship clearly: the final work should appear as though it took countless hours to create, with every detail considered by someone at the top of their field. Stay specific about the aesthetic direction while leaving enough interpretive space for original visual choices.

## Philosophy Examples

Concrete Poetry:

- Philosophy: communication through monumental form and bold geometry.
- Visual expression: massive color blocks, sculptural typography, Brutalist spatial divisions, Polish poster energy, and architectural clarity.

Chromatic Language:

- Philosophy: color as the primary information system.
- Visual expression: geometric precision where color zones create meaning, combining color theory with diagrammatic rigor.

Analog Meditation:

- Philosophy: quiet visual contemplation through texture and breathing room.
- Visual expression: paper grain, ink bleeds, vast negative space, and a Japanese photobook sensibility.

## Canvas Creation

Use the design philosophy to craft museum- or magazine-quality static work.

- Use repeating patterns and precise shapes when they support the concept.
- Treat the abstract philosophy as a rigorous visual system.
- Add sparse, clinical typography and systematic reference markers.
- Anchor the work with simple phrases positioned subtly.
- Use a limited color palette that feels intentional and cohesive.
- Make the finished artifact look painstakingly made, not quickly generated.

The final visual should feel like the result of countless hours of craft: balanced, detailed, coherent, and deliberate down to small spacing, alignment, texture, and compositional decisions.

## Execution Notes

- Prefer generated or programmatic `.png`/`.pdf` output over screenshots when the user asks for a static piece.
- Use a real canvas size appropriate to the artifact, such as poster, square art print, presentation cover, or social graphic.
- Save the philosophy `.md` alongside the visual output.
- Verify the final image or PDF visually when tools are available.
