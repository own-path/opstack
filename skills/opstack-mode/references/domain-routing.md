# Route work into the selected 146 skills

The domain skills are bundled beside the opstack workflow folders. Read the relevant domain SKILL.md and its required supporting references before implementing or assigning the task. Provide these paths/instructions to workers explicitly. Load only the skills needed for the task, not all 146. For plugin-only tools unavailable in the developer’s environment, state the limitation and use an actually supported equivalent where appropriate.

Use opstack-swarm as the native orchestrator; the imported swarm skill is retained as a domain skill for its original QuickJS environment, not a replacement for opstack’s native workflow.
