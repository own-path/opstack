# The 146 skills in opstack

These are the selected domain skills, bundled as real folders under skills/ with their supporting files. The 13 opstack workflow skills route work into this library; they are not a replacement for it. Native plugins and the default installer discover all 159 primary skills.

Two Claude-specific alternate versions are stored under variants/claude; the Python installer selects them for Claude. Original third-party files retain their own terms; the root MIT license covers original opstack content. Databricks license/notice files are included with its skills. See provenance.json for source records and normalized metadata.
